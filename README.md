# The Equation Room — La ruta de Nébara

Videojuego educativo de aventura arqueológica para practicar Lógica y Matemática Básica (FUN-02).

## Estado
**Prototipo 4.0:** exploración en primera persona con perspectiva 3D simulada (raycasting), artefactos interactivos, cinco mecanismos algebraicos, sonido Web Audio y protagonista ilustrado: Damián Vela.

**Importante:** Damián todavía es arte conceptual 2D integrado a la interfaz; aún no existe un modelo 3D animado jugable, ni una selva exterior implementada.

## Jugar
Abrir `index.html` en un navegador moderno. Controles: WASD para desplazarse, flechas o arrastre para mirar, E para examinar. El sonido se activa tras una interacción.

## Principios
- El jugador debe deducir el procedimiento: no se muestran los nombres de los temas.
- Validar operaciones matemáticas y restricciones de dominio con rigor.
- Priorizar diversión, exploración y retroalimentación formativa.
- Cada avance se desarrolla mediante issues, ramas y pull requests.

## Estructura prevista
- `index.html`: prototipo jugable.
- `assets/`: recursos gráficos del personaje.
- `docs/ROADMAP.md`: hoja de ruta.
- `docs/QUALITY.md`: criterios de calidad.
