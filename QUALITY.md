# Calidad y riesgos conocidos

Este repositorio parte de un prototipo HTML y no de un motor 3D completo.

- El mundo usa raycasting / perspectiva 3D simulada; las ilustraciones de Damián son 2D.
- La selva exterior todavía es un objetivo de diseño, no una escena implementada.
- Las respuestas se validan con reglas específicas; todavía no existe álgebra simbólica general. Comprobar equivalencias, signos y restricciones antes de calificar la implementación como correcta.
- Verificar especialmente el altar racional con dominio `x ≠ -4, 1`.
- Revisar en el navegador interacción, colisiones, audio y dimensionamiento de pantalla.
- Priorizar tests antes de introducir nuevos acertijos.
