# Calidad y pruebas

## Criterios
- Cada acertijo debe tener una solución matemática comprobada.
- Deben aceptarse representaciones equivalentes válidas sin aceptar expresiones incorrectas.
- Las fracciones algebraicas conservan las exclusiones del dominio original.
- No mostrar al jugador etiquetas como «factorización» o «monomios» antes de resolver.
- Audio opcional, volumen moderado y controles accesibles.
- Verificar tanto teclado como interacciones de ratón y dispositivos táctiles.
